# Grow Up — Premium Personal Growth Dashboard

Versi desain premium untuk aplikasi habit tracker berbahasa Indonesia.

## Fitur
- Dashboard modern dengan hero gradient, progress ring, dan ringkasan.
- Checklist mingguan berwarna dan persentase otomatis.
- Statistik dengan grafik 7/30 hari, riwayat, dan pencapaian.
- Jurnal refleksi dengan prompt cepat dan penyimpanan otomatis.
- Profil dengan jadwal mingguan, preferensi tema gelap, dan reset data.
- Kustomisasi nama tampilan dan warna aksen.
- Editor jadwal: tambah, ubah ikon/nama/catatan, dan hapus kegiatan pada tiap hari.
- Ekspor dan impor cadangan JSON untuk memindahkan data secara manual antarperangkat.
- Tema gelap, desain responsif, animasi halus, serta ikon aplikasi.
- Penyimpanan lokal browser; tidak memerlukan akun aplikasi atau biaya langganan.
- Catatan: sinkronisasi otomatis antarperangkat belum diaktifkan; ekspor/impor JSON dapat digunakan sebagai pemindahan data manual.
- PWA/offline cache setelah hosting HTTPS dan pembukaan pertama.

## Jadwal
- Setiap hari: belajar/membaca hadis dan menulis jurnal/artikel.
- Senin/Rabu/Jumat: fikih dan olahraga.
- Selasa/Kamis/Sabtu: membaca pengembangan diri.
- Sabtu juga olahraga.
- Minggu: evaluasi tulisan dan pemulihan.

## Cara deploy gratis
Unggah isi folder ini (bukan ZIP) ke root repository GitHub, lalu aktifkan GitHub Pages dari branch `main`, folder `/ (root)`. Buka alamat HTTPS yang diberikan GitHub di Chrome Android dan gunakan menu Chrome → Install app / Tambahkan ke layar utama.

## Catatan
Ini proyek PWA, bukan APK native. Untuk menghasilkan APK, gunakan pengemas PWA yang mendukung Android (misalnya PWABuilder) setelah proyek dihosting. Pengingat browser bersifat terbatas dan tidak dijamin aktif ketika browser ditutup. Checklist dan jurnal disimpan di localStorage perangkat/browser.
